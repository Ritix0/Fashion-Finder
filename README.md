# Fashion Finder — Поиск одежды по деталям (Wildberries & Ozon)

Автономный клиентский сервис подбора одежды по естественному описанию с непрерывным накоплением характеристик, показом карточек с артикулами прямо на странице и готовностью к размещению на GitHub Pages.

---

## Архитектура и функционал

1. **Непрерывное накопление контекста:**
   - Каждое сообщение пользователя дополняет текущий список параметров без стирания ранее найденных свойств (цвет, крой, ткань, воротник, принт).
   - Интерактивные теги с возможностью удаления любого критерия в один клик.

2. **Выдача товаров ВСЕГДА ровно 30 с Wildberries и 30 с Ozon (всего 60):**
   - Полностью динамическая генерация на лету под любое произвольное описание (без локальных файлов базы).
   - Карточки товаров с точными артикулами, рейтингом и ценами.
   - Кнопка быстрого копирования артикула в буфер обмена в один клик.
   - Прямые ссылки на конкретные карточки: `wildberries.ru/catalog/{id}/detail.aspx` и `ozon.ru/product/{id}/`.
   - **100% отображение изображений**: прямой CDN Wildberries + мгновенный fallback на высококачественные векторные fashion-визуалы в темной эстетике, защищенные от блокировок провайдеров и сбоев сети.

3. **Синтез формул для прямого поиска Google:**
   - Вкладка прямого поиска с фильтрацией по сайтам маркетплейсов (`site:wildberries.ru/catalog ...` и `site:ozon.ru/product ...`).

4. **Отказоустойчивая каскадная ротация ИИ-моделей:**
   - Приоритетная связка: **DeepSeek-V4.1-Flash** (прямой официальный API / deepseek-chat) + **OpenRouter** + шлюз **Pollinations AI**.
   - Полная независимость от домашнего ПК: работает 24/7 с любого смартфона через GitHub Pages.

5. **Дизайн и эргономика (стандарты 2026):**
   - Эстетика Dark Tech Luxe / Minimalist Editorial (глубокий обсидиановый фон `#090b0e`, без кислотных градиентов).
   - Чистая типографика на базе шрифта **Plus Jakarta Sans** и моноширинного **JetBrains Mono**.
   - Адаптивная верстка под смартфоны: минимальные зоны нажатия 44×44px, безопасные отступы под плавающий dock ввода (`env(safe-area-inset-bottom)`).
   - Векторные SVG-иконки для всех элементов управления.

6. **SEO и GEO (AI Overviews):**
   - Микроразметка Schema.org (`WebApplication`, `FAQPage`, `ItemList`).
   - Мета-теги OpenGraph и Twitter Cards для социальных сетей и мессенджеров.

## Развертывание на GitHub Pages

Сайт работает полностью на стороне клиента (HTML5, CSS3, JavaScript Fetch API) и не требует бэкенд-сервера или включенного ПК:

1. Создайте публичный репозиторий на GitHub (например, `fashion-finder`).
2. Загрузите файлы `index.html`, `style.css` и `app.js` в корень репозитория.
3. Откройте **Settings** → **Pages**.
4. В разделе **Build and deployment** укажите:
   - **Source:** Deploy from a branch
   - **Branch:** `main` (или `master`)
   - **Folder:** `/ (root)`
5. Нажмите **Save**. Ссылка станет доступна через минуту: `https://<ваш_логин>.github.io/fashion-finder/`.
