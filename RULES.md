# Правила проекта Fashion Finder

## Модель ИИ
- **Единственная разрешенная модель:** `DeepSeek-V4.1-Flash` (в коде: `deepseek-v4.1-flash`).
- Категорически запрещено использовать `deepseek-chat`, `deepseek-flash` или любые другие старые или посторонние названия.
- Все запросы обрабатываются исключительно моделью `deepseek-v4.1-flash`.

## Обязанности ИИ (DeepSeek-V4.1-Flash):
1. Модель самостоятельно исправляет любые опечатки, сленг и пропущенные буквы («сндалей» → сандалии, «жжёлтые» → желтые, «велик» → велосипедки, «кросы» → кроссовки).
2. Вычищает слова-паразиты («типа», «как», «вроде», «купить», «найди»).
3. Выносит цвет на первое место в поисковом запросе `google_query` (например: «желтые тапочки сандалии»).
4. Никаких хардкодных словарей опечаток в JS — всю нормализацию делает только `DeepSeek-V4.1-Flash`.
